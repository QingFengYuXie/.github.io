This directory contains the `rem--l1` Rem spritesheet from
[legeling/awesome-codex-pet](https://github.com/legeling/awesome-codex-pet/tree/main/pets/rem--l1).

non-commercial repository redistribution. The spritesheet is used here only
as the interactive desktop pet on this personal GitHub Pages site.
